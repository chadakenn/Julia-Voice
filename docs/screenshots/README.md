# Screenshot gallery notes

The SVG files in this folder are **reconstructions for documentation**, modeled after two verified onn 4K Pro field-test photos. They are **not original screen captures** and should not be presented as screenshots of the Glass v0.5 skin.

The real on-device reference photos show:

- `conversation-preview.svg` reflects the **full-screen Assist response**: “What time is it?” → “5:07 AM”. The user confirmed text-to-speech was audible through the TV speakers.
- `overlay-preview.svg` reflects the **floating overlay above Google TV Home**: connected/authenticated, TALK / STOP / CLOSE visible.

## Replacing the previews with device photos

Preferred future files:

- `assist-response-onn-tv.jpg`: real photo of the working full-screen answer
- `floating-overlay-on-google-tv.jpg`: real photo of the floating panel above the launcher

Before publishing, crop away unnecessary surroundings, blur personal account/profile pictures, and double-check that no access tokens, QR pairing codes, security cameras, account data, or private addresses are visible.

When actual photos have been uploaded as repository image assets, replace the two Markdown image paths in the root `README.md` and change the caption from **illustrative previews** to **actual onn 4K Pro field-test photos**.

**Do not claim that these are v0.5 Glass screenshots**: that version has not yet been photographed and verified on the TV.
