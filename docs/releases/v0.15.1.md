# Kellie's Voice v0.15.1

Patch release for Home Assistant discovery and branding.

## What's new
- **Manual pairing when mDNS cannot discover the TV:** on the onn box open **Settings → Home Assistant layout → Show this TV's pairing ID**; in Home Assistant choose **Settings → Devices & services → Add Integration → Kellie's Voice** and enter the displayed UUID. Keep Home Assistant layout ON.
- The previous Add Integration screen no longer aborts with `use_discovery`; it offers a real pairing form. Automatic zeroconf discovery remains available.
- Add original copper house/microphone integration icons (`brand/icon.png` and `brand/icon@2x.png`) for Home Assistant 2026.3+. HACS itself may display a placeholder for local custom integration icons due to its upstream frontend issue.
- Update Android app to `versionCode 16`, `versionName 0.15.1`; Home Assistant integration version is also 0.15.1.
- Preserve Night Signal, YouTube ducking, scrolling, launcher reliability, and opt-in Frigate snapshot / HA announcement functionality.

## Install
- TV: install signed `app-release.apk` over existing installation. **Do not uninstall.**
- HA: download Kellie's Voice **v0.15.1** from HACS and restart HA.
- Pair through discovery or manually with the exact ID displayed on the TV.

Automatic discovery requires mDNS between the TV and HA; manual pairing does not. The TV still needs a valid authenticated Home Assistant connection for layout sync and alerts.
