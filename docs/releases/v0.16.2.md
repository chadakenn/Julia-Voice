# Kellie's Voice v0.16.2 — voice-close camera controls

- Adds the **Home Assistant `kellies_voice.hide_camera`** action to instantly dismiss a live or snapshot camera popup on one TV or all paired TVs.
- The Android TV listener subscribes to a scoped authenticated Home Assistant event `kellies_voice_hide_camera`; only the camera window is removed. It does not stop normal TV programming, hide text announcements, or use the microphone.
- Live camera duration remains configurable in the Home Assistant action (15–180 seconds). Expose `duration_seconds` to Assist in the camera script, or create an explicit “Show doorbell for 30 seconds” script for agents that cannot pass parameters.
- Both cameras have already shown actual moving video on an onn 4K Pro using v0.16.1. This release leaves the proven `TextureView` player, HLS validation and snapshot fallback unchanged.
- Maintains the same Android app ID and signing key; versionCode is 19. Upgrade *in place* from v0.16.1 through Settings → Check for app updates.
- **HACS integration must also be updated to v0.16.2 and Home Assistant restarted** to register the new `hide_camera` action.
- After installing the APK, **open Kellie's Voice once** so the opt-in TV alert receiver connects again.

**Verification pending on real TV:** spoken close command through Julia, 30-second speech command, early release of HLS video. Back-button dismissal isn't supported by the passive non-focusable overlay.
