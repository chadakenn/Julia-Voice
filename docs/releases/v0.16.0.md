# Kellie's Voice v0.16.0

This update makes **experimental live camera viewing** available through the normal, checksum-verified in-app updater. Existing announcement, Frigate snapshot and layout functions remain unchanged.

## Updates in this release

- New Home Assistant `kellies_voice.show_live_camera` action: request a live HLS view of a configured camera for 15–180 seconds (default 90 seconds).
- The Android TV app plays muted live video in a temporary non-focusable overlay, so the current show or YouTube video keeps its own audio and remote focus.
- The TV requests the stream through its authenticated Home Assistant connection. No arbitrary camera URLs, RTSP credentials or authentication tokens are sent in automation events.
- End-of-view timeout releases the video player. Existing person-detection popups keep using quick snapshots.
- Home Assistant voice-assistant scripts can call the live service when installed and exposed.
- Includes the previous tested HA remote overlay controls, targeted TV announcements, Frigate camera snapshots, icon and manual pairing.

## Upgrade from v0.15.1

1. Open **Kellie's Voice → SETTINGS → Check for app updates** on your onn 4K Pro, then choose **Download update** and confirm Android's installer. **Do not uninstall the app.**
2. In Home Assistant's **HACS**, download Kellie's Voice **v0.16.0** and restart Home Assistant.
3. Test **`kellies_voice.show_live_camera`** from Developer Tools with camera.driveway or camera.doorbell. The camera must support HA streaming.
4. Scripts **Show driveway camera live on TV** and **Show doorbell camera live on TV** can be exposed to Assist for Julia voice requests.

**Experimental notice:** The HLS live-video overlay has passed Android unit tests, HA Python tests, HACS validation and signed APK build, but has **not yet been field-tested on the physical onn TV**. Live video may need follow-up changes for stream compatibility or delay. Existing tested snapshots and announcements are the fallback.

APK: `app-release.apk` (same Android application ID and signing key), SHA-256 in `update.json`. Current Android `versionCode`: 17.
