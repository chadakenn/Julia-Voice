# Kellie's Voice v0.16.3 — adjustable camera popups and resilient TV alerts

**New:** per-TV Home Assistant controls for the position and size of **text announcements**, **Frigate still snapshots**, and **live muted camera windows**. Choose Top left, Top right, Bottom left, Bottom right, or Center; size Small, Medium or Large. Existing Top right/Medium defaults remain. Voice assistant panel placement is unchanged.

**Better delivery after an update/reboot:** the Android app attempts to restart its already opt-in `TvEventsService` when the TV boots or the APK is upgraded in place. If Android TV blocks the foreground service, the app offers **Settings → TV alert status → Resume TV alerts** and may show a single notification. It does not start the microphone or silently enable notifications, and never replays missed events. Some standby states and force-stop require reopening the app.

**Preserved:** the verified-on-device `TextureView` live HLS playback for driveway/doorbell, mute/TV audio focus, snapshot fallback, and the v0.16.2 **`kellies_voice.hide_camera`** action. No streaming tokens are exposed in HA events.

**Install BOTH components:** Android v0.16.3 (versionCode 20) via Kellie's Voice → Settings → Check for app updates, and HACS integration v0.16.3 followed by a Home Assistant restart. Android's package ID and private signing key are unchanged; don't uninstall the existing app.

**Field-test still required:** popup placement at all positions, sizes, alert recovery on reboot and app update, automatic reconnection/permission handling. The previous v0.16.1 moving-video confirmations should not be mistaken for testing these v0.16.3 changes.
