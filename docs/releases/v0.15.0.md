# Kellie's Voice v0.15.0

First combined public release of the **Android TV assistant** and **Kellie's Voice Home Assistant custom integration**.

## Android TV updates
- Night Signal dark/brass theme, adjustable overlay position and size
- Better ⭐ overlay startup and long-answer scrolling with the TV remote
- YouTube/TV audio focus while recording and speaking, restoring video sound afterward
- Self-healing Home Assistant connection and safer app updates
- Optional microphone sensitivity settings (quiet, normal, TV-on)
- Opt-in HA overlay layout controls, on-screen announcements and Frigate camera **snapshots**

## Home Assistant integration
- `custom_components/kellies_voice` is installable as a HACS custom repository
- Per-TV layout and visibility options
- `kellies_voice.announce` and `kellies_voice.show_camera` services
- Frigate person-detection blueprint

## Install and verify
- **Android TV:** install attached `app-release.apk` over your currently signed app. **Do not uninstall**, or you'll lose device settings and encrypted HA credentials. You can also use Kellie's in-app updater.
- **Home Assistant:** first add `https://github.com/chadakenn/Kellies-Voice` in **HACS → ⋮ → Custom repositories** as **Integration**. Then select version v0.15.0, restart HA, enable **Home Assistant layout** on the TV and add the discovered device.
- Enable **TV announcements & cameras** separately on the TV for visual notifications.

## Tested / limitations
Scrolling, YouTube audio muting and ⭐ double-launch were verified on an onn 4K Pro. **The complete HA announcement/Frigate popup path still needs end-to-end on-device testing.** Camera alerts show authenticated still snapshots, not live picture-in-picture video. Android may stop the optional TV event receiver; it is not guaranteed 24/7.

See `docs/TV_EVENTS.md` and `custom_components/kellies_voice/README.md`.
