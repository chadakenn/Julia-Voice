# Kellie's Voice v0.16.4

Owner-approved update for on-TV testing. Adds named voice timers with countdown pills, two chimes followed by optional configurable Android TTS speech and a short pause, repeating until dismissed. Audio-focus recovery and unavailable Dismiss controls have regression coverage. Includes optional Aurora Glass and seven-day weather popup/settings.

Update Android through Settings → Check for app updates, then confirm the Android installer. Existing package identity and private release signing key are preserved. Update the matching HACS integration to v0.16.4 and restart Home Assistant. Do not uninstall the existing app. Timer/voice setup: [VOICE_TIMERS.md](https://github.com/chadakenn/Kellies-Voice/blob/v0.16.4/docs/VOICE_TIMERS.md).

Android build/unit tests and HA integration tests gate publication; physical onn QA of the new timer/weather/theme behavior remains pending. Timer alerts are an awake-TV feature without an exact-alarm/wake-lock guarantee. PR #46 hands-free follow-up listening is not included. Existing v0.16.3 release remains available.
