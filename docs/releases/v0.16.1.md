# Kellie's Voice v0.16.1 — live camera compatibility hotfix

This version responds to the first onn 4K Pro live-video test: Home Assistant successfully delivered the on-demand camera popup, but the video area displayed black / an error.

- Switches Media3 HLS rendering from a `SurfaceView` to an Android `TextureView` compatible with compositing in overlay windows.
- Shows a **camera snapshot as a fallback** while HLS starts or if it fails, instead of a blank black rectangle. Fallback is clearly labeled and must not be mistaken for moving live video.
- Displays a short diagnostic error code from the Home Assistant stream request or the Media3 player. Never prints any URLs, stream token, access token or exception details.
- Uses the explicit HLS MIME type to avoid stream-source ambiguity.
- Keeps announcements, Frigate person snapshots, overlay position sync and muted TV audio untouched.
- Raises Android versionCode from 17 to 18. Same application ID and signing key as v0.16.0. Update via the in-app menu, without uninstalling.

**Live video remains experimental:** Test with `kellies_voice.show_live_camera` and confirm the image visibly moves and the caption becomes **LIVE · muted**. Report any on-screen error code if moving video still fails. HACS integration v0.16.0 continues to work without a separate HACS update for this patch.

## Confirmed onn 4K Pro hardware result (October 22, 2026)

After installing **Android app v0.16.1** and opening its main app to restart the opt-in event receiver, the owner confirmed that a `kellies_voice.show_camera` driveway snapshot appeared and the subsequent `kellies_voice.show_live_camera` **driveway video was visibly moving**. This is the first confirmed on-device live HLS playback of Kellie's Voice.

**Important remaining testing:** Doorbell and other live camera feeds, reliability after TV standby/reboots, and whether automatic event receiver startup survives future app updates. The screenshot gallery still needs an authentic on-device capture; no screenshot has been fabricated.
